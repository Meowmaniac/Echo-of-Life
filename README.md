# Echo of Life

Echo of Life is an iOS application for keeping track of the things that shape our lives — from small desires and dreams to experiences, challenges, and achievements.

The idea is to create a personal map of life that makes it possible to look back at what has happened, see how things are connected, and keep track of what still lies ahead.

## What you can keep track of

* Desires
* Dreams
* Experiences
* Challenges
* Achievements
* Values
* Reflections

Life items can be connected to each other and associated with personal values. Any meaningful moment can also be marked as an achievement.

## Tech Stack

* Swift
* SwiftUI
* SwiftData
* MVVM
* Repository Pattern
* Swift Concurrency
